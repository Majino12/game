# 更新日志

本文件记录可游玩的版本变化。源码中的存档格式版本与游戏版本分别编号。

## 1.2.0 — 2026-10-19

### 角色、路线与战斗

- **角色主动技能**：按 `E` 使用专属能力。奶油「守护脉冲」提供护盾、1.2 秒保护与近处清障，冷却 12 秒；莓莓「流星跃」立即跃起、保留后续空跳，提供至少 4 秒磁铁和 0.8 秒保护，冷却 10 秒；星云「星环爆发」清除敌弹和前方可见障碍，回复 30 能量、对可攻击 Boss 造成 35 伤害，提供 0.5 秒保护，冷却 14 秒。原有角色解锁继续有效。
- **四张地图**：云野弹簧、流金沙丘宝箱、荧光林地能量球、浮空遗迹低重力与高空金币。地图具有不同的障碍权重；开局仍保留循序教学。每局从云野开始，约每 500 米等待安全状态后切图，顺序随机且不连续重复；下次距离从实际切图点重新计算。
- **三类守卫**：首战保留疾风蜂王的低高单波；后续以随机袋轮换蜂王、风暴守卫和晶岩巨像，相邻不会重复。风暴改为同高度双波，晶岩巨像以瞄准弹、低波、高波循环，瞄准高度在预警开始时锁定。保留弱点期、半血加速与逐轮血量成长。
- **地图与练习选择页**：可查看各地图机制，并选择任一种守卫练习。练习允许使用当前角色技能，仍不应用工坊升级、不保留天赋、不提供永久奖励。HUD 增加技能冷却与地图提示。

### 兼容与开发

- 沿用第 2 版存档格式，保留已有钱包、纪录、角色、工坊和合约进度；第 1 版存档仍按既有规则迁移。本局地图、技能冷却与天赋不跨局保留。
- 继续使用已有 103 个 Kenney CC0 图片与音效及本地合成音乐，无需新增素材下载；地图与 Boss 差异由已有素材和程序绘制实现。
- 命令行新增 `--character beige/pink/purple`、`--boss-kind bee/storm/crystal`，以及 `--scene maps`、`--scene practice`；`--scene boss` 可直接进入指定守卫练习。
- CI 配置覆盖 Python 3.9 / 3.12、十一个界面场景、三个角色参数、三类 Boss 各 240 帧及异目录启动。本地通过 126 项自动测试；三次各 600 秒自动冒险均无受伤或护盾抵消事件，分别击败 19 / 19 / 18 个 Boss，覆盖全部地图与守卫。实窗验证角色技能、练习选择、暂停退出及英文菜单。CI 所配置的场景、守卫、角色及异目录启动命令也在本地通过；GitHub CI 结果以对应提交记录为准。

## 1.1.0 — 2026-10-19

### 新增玩法与成长

- **Boss 后选天赋**：普通冒险击破守卫后，从最多三项随机给出的未满级天赋中选一项。六种天赋为轻翼、弱点专注、充能核心、疾速连射、磁力扩展和连击节拍；轻翼上限 1 级，其余 3 级。全部满级后提供可重复的补给箱，获得 40 金币并补满磁铁时间。天赋只在当前冒险有效。
- **两类守卫**：蜂巢按低、高交替，风暴按高、低、低、高循环；两种模式交替登场。后续 Boss 每次增加 20 点血量，从 160 起，最高 240。
- **升级工坊**：磁铁持续时间、金币充能、冲刺时长各有三级永久升级。逐级价格为 80 / 160 / 280 金币；每级分别增加 2 秒、每币 0.5 能量、0.35 秒冲刺时间，下次普通冒险生效。
- **远征合约**：每累计 1500 米奖励 40 金币、250 枚本局金币奖励 50 金币、击破 3 个 Boss 奖励 100 金币。普通冒险结算时自动领奖并继续升阶，一次可完成多阶；单局目标奖励和合约奖励不会反复计入金币合约。
- **成长与更新页面**：主菜单提供工坊、远征合约、更新说明；天赋页按 `1` / `2` / `3` 或点击卡片选择。`Esc` 从工坊、合约、更新说明返回菜单，在天赋页会结算当前冒险并返回菜单。

### 兼容与运行

- 第 2 版 `save.json` 兼容第 1 版及未标版本的已有存档，保留钱包、纪录、角色和设置。工坊、累计进度及合约领奖阶数从零开始，不追溯旧历史；下一次保存写入新格式。
- Boss 练习不应用工坊升级，也不产生永久金币、纪录、局数、合约进度或战后天赋收益。
- 沿用基础版的 103 个 Kenney CC0 图片和音效、现有资源路径及合成背景音乐，不需要追加素材下载。
- 增加 `--scene workshop`、`contracts`、`perks`、`changelog`，CI 配置覆盖九个场景；新增成长、天赋和存档迁移验证。本版在本地通过 85 项自动测试，并验证实窗页面导航、数字键选天赋和继续冒险。

## 1.0.0 — 基础版

- 重构为 Pygame CE 横版跑酷：二段跳、滑铲、空中速降、金币连击、磁铁、护盾、主动冲刺与金币狂欢。
- 增加蜂巢守卫、攻击预警、低高能量波、弱点射击、半血加速、击破奖励和免费 Boss 练习。
- 提供三个外观角色、三个单局目标、本地钱包及个人纪录，支持中英文、静音、暂停、失焦自动暂停、全屏与窗口等比例缩放。
- 重新选用带来源清单和许可证的 Kenney CC0 素材，背景音乐在本地合成。旧原型源码可在 Git 历史中查找；计分方式不同，旧 `highscore.txt` 不导入新纪录。
- 提供 macOS / Windows 启动脚本、第 1 版原子存档与损坏备份，支持任意工作目录启动、固定随机种子及不读写用户存档的无窗口测试。
- 建立跑酷、Boss、输入、存档测试和 Linux Python 3.9 / 3.12 CI，覆盖基础五场景与 Boss 240 帧渲染。
