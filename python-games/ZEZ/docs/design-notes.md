# ZEZ 1.1.0 设计说明与同类机制对比

记录日期：2026-10-19。本文区分官方资料中的机制事实与本项目的设计判断；数值以 ZEZ 源码和[游戏说明](../README.md)为准。

## 从单局手感到持续目标

ZEZ 基础版已经有二段跳、滑铲、连击、冲刺和可躲避的 Boss 攻击。继续游玩时，主要问题是：重复 Boss 的节奏相同，击败后的选择少；金币主要用于三个角色外观；同一组单局目标每次重新开始，失误后的长期进展不明显。

本版把成长分为两层：Boss 后选择的天赋只影响当前冒险；工坊升级和远征合约保存在本地，影响后续冒险。这样既能让同一局逐步形成不同玩法，也能让一次失败留下可见的进展。

## 官方机制与本版取舍

| 同类机制与官方依据 | ZEZ 基础版的不足 | 1.1.0 的实现与设计判断 |
| --- | --- | --- |
| Jetpack Joyride 完成任务获得星级，再推进等级与 Prestige 徽章。[Halfbrick 官方说明](https://halfbrick.helpshift.com/hc/en/4-jetpack-joyride/faq/723-how-do-i-earn-prestige-badges/) | 固定的三个单局目标会随每次开局重置，缺少可累计的目标。 | 增加距离、金币、Boss 三条远征合约；结算时累计进度、自动发奖并进入下一阶。保留单局目标，让短目标和长目标同时存在。 |
| Halfbrick 的高分指南说明不同 Gadget 能以不同方式帮助玩家，并鼓励组合选择。[Halfbrick 官方指南](https://halfbrick.helpshift.com/hc/en/4-jetpack-joyride/faq/726-how-do-i-increase-my-high-score/) | 击败 Boss 主要得到固定数值奖励，后续操作与上一段接近。 | Boss 后从本次给出的天赋中选择一项，形成跳跃、射击、能量、吸币或连击方向。三选一是本项目的实现，不是对官方 Gadget 系统的复刻。 |
| Subway Surfers 可用金币延长喷气背包、超级跑鞋、磁铁及倍率道具的持续时间。[SYBO 官方 Boosts 说明](https://sybo.helpshift.com/hc/en/5-subway-surfers/faq/154-boosts/) | 外观解锁完成后，金币缺少直接改变游玩体验的用途。 | 工坊提供磁铁持续时间、金币充能、冲刺时长三类永久升级，显示当前等级和下一级价格，最高三级。所有升级只花游戏内金币。 |
| Subway Surfers 的任务以三个一组推进，完成整组提高得分倍率，达到上限后转为其他奖励。[SYBO 官方 Missions 说明](https://sybo.helpshift.com/hc/en/5-subway-surfers/faq/143-missions/) | 固定目标完成后，再跑一局的目标变化较少。 | 合约保留三条清楚的进度，完成后继续升阶。这里借鉴的是持续进度的呈现；ZEZ 的合约奖励是金币，不会永久放大得分倍率。 |

上表的“有助于形成玩法”“让失败留下进展”是设计目的，尚未通过大规模玩家研究验证。官方资料也不证明这些取舍适合所有跑酷游戏。

## Boss、天赋与节奏

首次 Boss 继续保留入场预告、低波跳跃、高波滑铲和发射后的弱点期，便于理解基本应对。后续遭遇交替使用蜂巢与风暴模式，并提高血量，让玩家需要重新观察攻击节奏。攻击仍保留可读的预警。

Boss 的固定金币、分数和补给奖励负责即时反馈；随后出现的天赋选择负责改变下一段玩法。通常给出三项未满级天赋，剩余不足三项时只显示剩余项，全部满级后改为补给箱。选择期间模拟暂停，玩家可以阅读卡片。天赋在本局结束后清空，工坊升级长期保留；两者在界面与说明中分别标注。

## 奖励边界与兼容

- 普通冒险统一结算金币、目标奖励和远征合约，避免重复进入结算页重复发奖。
- Boss 练习供学习攻击节奏，不应用工坊升级，也不产生钱包收益、合约进度、永久纪录或战后选卡。
- 新增成长字段与已有本地记录一起保存；旧版 `save.json` 的兼容细节见[更新日志](../CHANGELOG.md)。更早原型的 `highscore.txt` 不会转成新分数。
- 继续使用项目已有 Kenney CC0 素材，Boss 差异由已有图片与程序绘制表达。本次没有引入竞品图片、角色、声音或源码。

## 尚余差距

合约虽然可以累计和升阶，但目标类别仍固定为距离、金币与 Boss；这不等于随机任务、每日挑战或赛季系统。两类 Boss 与六种天赋也还不是完整关卡库。后续是否增加新内容，应先观察现有分支的使用率、击败时间、金币收入与升级后的通过率，避免仅靠增加血量拉长战斗。

本版没有联网排行榜、云存档、每日重置、真实付费或永久天赋树。无需这些功能也能完成“跑酷 → Boss → 天赋 → 继续冒险 → 结算 → 工坊”的离线循环。

## 核验范围

本版在本地通过 85 项自动测试，并完成工坊、合约、更新说明导航以及数字键选天赋、恢复冒险的实窗操作检查。无窗口渲染检查覆盖原有五个场景以及工坊、合约、天赋、更新说明；CI 配置在 Linux Python 3.9 / 3.12 上重复执行测试与渲染检查。自动测试能发现规则和流程错误，不能替代玩家对节奏、难度和趣味性的评价。
